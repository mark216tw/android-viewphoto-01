# 使用指南

## 第一次啟動

1. 開啟 `mini相片瀏覽器`。
2. 依系統提示授予圖片存取權限。
3. Android 14 以上可選擇完整相片權限，或只授權指定圖片。

## 瀏覽相片

- 主畫面底部的「相片」會依拍攝或新增時間顯示圖片。
- 「資料夾」會依圖片所在資料夾分類。
- 進入資料夾後，按工具列返回按鈕或手機系統返回鍵可回到資料夾清單。
- 點選縮圖可進入全螢幕瀏覽。
- 點一下圖片可顯示或隱藏控制列。
- 在原始比例雙擊可放大至 2.5 倍；已放大時雙擊可還原。
- 使用雙指縮放，放大後可單指拖曳圖片。
- 點選資訊按鈕可查看檔名、尺寸、大小、日期、資料夾及 MIME 類型。

## 從其他 App 開啟圖片

- 在其他 App 的開啟選單選擇本 App，可直接瀏覽圖片。
- 在編輯選單選擇本 App，可直接進入圖片編輯器。
- 分享單張圖片時選擇本 App，會先進入圖片瀏覽畫面；目前不支援一次接收多張圖片。

## 編輯圖片

在圖片瀏覽頁點選「編輯」，或從 Android 截圖工具的編輯清單選擇本 App。

### 工具

- **畫筆**：以不透明顏色繪圖。
- **螢光筆**：以半透明顏色標記。
- **橡皮擦**：清除目前仍可編輯的筆畫。
- **模糊**：在指定區域顯示像素化模糊效果。
- **裁切**：拖曳四角或移動選取區域後套用。
- **旋轉**：順時針旋轉 90 度，既有筆畫仍可復原或擦除。
- **水平翻轉**：將圖片與筆畫同步左右翻轉。

四種筆刷型工具使用 `5dp..32dp` 的固定螢幕粗細。滑桿右側會顯示即時預覽；各工具粗細，以及畫筆與螢光筆顏色，會在下次編輯時保留。

### 復原與重做

- 頂部左側的復原與重做按鈕以筆畫為單位運作。
- 旋轉及水平翻轉後，筆畫歷史仍會保留。
- 裁切會先合併目前效果，因此裁切前的筆畫不再能逐筆復原。

### 儲存與分享

- 儲存按鈕會另存 JPEG，不覆蓋原始圖片。
- 新圖片會存放在 `Pictures/MiniPhotoViewer`。
- 分享按鈕會建立暫存 JPEG 並開啟 Android 分享面板。

## 刪除圖片

從瀏覽頁點選刪除。Android 10 以上可能顯示系統確認視窗；刪除後無法由本 App 復原。

## 外觀設定

設定頁可選擇跟隨系統、淺色或深色模式，選項會保存在裝置上。

## 常見問題

### 為何看不到所有圖片？

確認已授予完整圖片權限。若只授權選定圖片，App 只能顯示該範圍。

### 為何編輯後產生新檔？

目前採用非破壞式另存設計，避免覆蓋原始相片。

### 為何 Pre-release APK 會顯示測試簽章？

`prerelease` 是測試發行 Build Type，刻意使用 Debug 金鑰，不是正式上線簽章。
